# Team Elimination mode `'td'` — "Ngã tư tử thần" crossroads map

## Context

The user wants a new team-vs-team mode modeled on CrossFire/Đột Kích's "Ngã tư tử thần" (Death Crossroads):

- **Round-based elimination**: no respawn during a round; dead players spectate until the round ends. A round is won by wiping the enemy team. No per-round time limit.
- **First to X round wins takes the match.** X is chosen at room creation (3/5/7/10), default 5. No overall match timer.
- **Map**: a symmetric crossroads — two team spawn zones at opposite ends, four corner buildings around a central intersection.
- **Weapons lie on the ground at FIXED positions** (same spots + same gun kinds every round, so players learn where their favorite gun is), near each team's spawn zone, mirrored. Players spawn pistol+knife and walk over a gun to pick it up (existing proximity pickup). Spawn position within the zone is random each round.
- Bots must play the mode.

Exploration confirmed: there is **no round machinery today** (`Phase = 'playing'|'ended'` only), but CTF already provides teams, friendly-fire prevention, team spawns, team HUD/results, bot goals, and a proximity drop/pickup system — all reusable.

## Key design decisions

1. **Dedicated schema fields, not `redScore`/`blueScore` reuse**: add `roundsRed`, `roundsBlue`, `round`, `roundLimit` (`uint8`) and `roundPhase` (`'live'|'intermission'`) to `RoomState`. Generalize the client's `CtfSummary` into `TeamSummary { mode: 'ctf'|'td'; red; blue; limit }` so the team results screen is reused.
2. **`isTeamMode(mode)` helper** (`ctf || td`) in `protocol.ts`. All CTF *team* machinery currently gated on `this.ctf` in `ArenaRoom` (`sameTeam`, team pick/color on join, `handleSelectTeam`, `rebalanceBots`, `setTeam`, bot team alternation, `spawnsFor`→`teamSpawns`, metadata `teams`) switches to a new `this.teams` getter. Flag/carrier code stays on `this.ctf`.
3. **Round state machine inside `phase === 'playing'`**: round end → `TD_INTERMISSION_MS = 5000` intermission (survivors keep walking, no respawns) → `startRound()` respawns everyone, `round++`. Reaching `roundLimit` calls the existing `endMatch()`.
4. **Round-end rule as a pure shared function** `roundWinner(alive, ready)` in new `shared/src/td.ts`: round only ends when *both* teams have ≥1 ready participant (prevents instant-round loops in a solo room); one side at 0 alive → other side wins; both at 0 in the same tick → `TEAM_NONE` = draw, no point, round still advances; otherwise `null` (round continues).
5. **Mid-round joiners**: `handleReady` in td marks `meta.ready` but only spawns if within `TD_JOIN_GRACE_MS = 10 000` of round start; otherwise they spawn at the next `startRound()`. Team switching keeps CTF rules (switching while alive kills you; in td you then wait for the next round — existing `setTeam` already behaves correctly since td ignores `respawnAt`).
6. **Fixed weapons**: `generateTdWorld` returns `GeneratedWorld.weaponSpots?: SpawnPoint[]` — **8 spots per side (16 total)**, mirrored. Pure `tdWeaponLoadout(weapons: WeaponMode)` in `td.ts` returns kinds per side: `[rifle, smg, shotgun, sniper] × 2` for `'all'`, blades `× 2` for `'sword'` (no taser/grenade packs — players spawn with `GRENADE_START` grenades). Server `layTdWeapons()` zips spots×loadout into `DropSchema`s **without `dropExpiry` entries** (never expire), clearing leftovers first; re-laid every round. Random timed drops disabled in td — gate only the schedule/spawn/expire half of `tickDrops`; the pickup loop must keep running.
7. **No timers**: `tickTimer` early-returns in td (`timeLeftMs` stays 0), metadata `endsAt: 0`; lobby hides the Duration select and shows "—" for time left; HUD swaps the timer for a rounds bar.
8. **Dead-spectator UX (minimal)**: keep today's death camera; replace the respawn countdown with "Spectating — back next round" while `roundPhase === 'live'` and "Next round in Ns" during intermission (from the `MSG.round` end event + `TD_INTERMISSION_MS`). Free-fly spectator cam is a non-goal.
9. **Bots**: `botTdGoal(self, { enemies, drops, hasGun, center })` in `td.ts` — no primary and a drop on own half → nearest drop; else nearest known enemy; else the crossroads center. `BotView.goal` is already generic; only `tickBots` needs the td supplier.
10. **`spawnPrimary` needs no change** — its `mode !== 'match'` guard already gives td pistol-only spawns; add a test.

## Map: `generateTdWorld(seed)` (`shared/src/worldgen.ts`)

64×64, red north / blue south, mirrored across z-mid (`mirrorZ(z) = sz-1-z`; generalize `scatterMirrored` to take an axis or add a z-variant). Reuse `fillTerrain`, `borderWall`, `wallCells`, `computeSpawnPoints`, `isStandable`.

- Noise ground h 3..5 (mirrored), border wall as today.
- **Crossroads**: two flattened h=3 roads, width 8 — N–S at x 28..35 (full z), E–W at z 28..35 (full x).
- **Four corner buildings** framing the intersection: hollow 9×9 brick rooms, walls 4 tall, 3-wide doorways on both road-facing sides, at x 15..23 / 40..48 × z 15..23, mirrored to z 40..48 — small new helper `roomAt(world, rect, doors)`.
- **Spawn zones**: z 2..11 (red) / 52..61 (blue) with a few mirrored `wallCells` cover pieces. `bases` = zone centers (`(32, z≈6)` + mirror) — feeds `spawnsFor`/`teamSpawns` and the preview camera.
- `spawnPoints`: `computeSpawnPoints(…, target 24, minDist 6, accept: z ≤ 11 || z ≥ 52)`.
- `weaponSpots`: 8 per side at z=13 (mirror z=50), x ∈ {12, 18, 24, 30, 34, 40, 46, 52}, y from column top.
- `dropZone` = intersection rect (unused for random drops). `generateWorldFor` gains the `'td'` branch.

## Risks

- **Client respawn-countdown assumption** (`game.ts:591`, `hud.ts:354`): unbranched, dead td players see a bogus "Respawning in…" forever.
- **Drops**: fixed spots must skip `dropExpiry`; only the spawn/schedule half of `tickDrops` may be disabled.
- **Stale grenades across reset**: clear `grenadeSim`/`state.grenades` in `startRound` or a round-1 grenade explodes into round 2. The `spawnEpoch` bump already invalidates in-flight poses/shots — rely on it.
- **Empty-team lock-in**: the "both teams have ≥1 ready player" guard in `roundWinner` is what stops a solo room from looping rounds instantly.
- **`tickTimer`/metadata `endsAt`**: forgetting either ends td matches at `durationMin` or shows nonsense lobby time-left.
- **`this.ctf` sweep**: any missed team gate silently enables friendly fire or breaks team spawns — integration test asserts no friendly damage.

## Implementation notes (as built, 2026-08-21)

Deviations from the plan above, discovered during implementation:

- **`roundWinner` counts participants, not ready players.** A player who
  readies mid-round past `TD_JOIN_GRACE_MS` (or during an intermission) is
  ready-but-waiting; counting them as "wiped" would hand the enemy an instant
  round the moment they join. The rule now takes per-team
  `{alive, inRound, ready}` (`RoundSide`): a side whose ready players are all
  outside the round draws the round (no point) so the restart spawns them in;
  a side with nobody ready freezes the round. `PlayerMeta.inRound` (set by
  `spawn()`) separates fighters from waiters.
- **Terrain noise is 3..4, not 3..5**, so the flattened roads (h=3) never
  have banks taller than one jumpable block.
- **8 weapon spots per side** (two of each primary gun / blade), not 4 — one
  of each was too few for 8-player teams.
- `TeamSummary` keeps the old `redScore/blueScore/captureLimit` field names
  (with a `mode: 'ctf' | 'td'` discriminator) instead of renaming them, to
  keep the results-screen churn small.
- **Round polish (same day, user feedback):** round results show as a big
  centre banner (`hud.roundBanner`, replaces the toast); every td spawn is
  frozen for `TD_FREEZE_MS = 3000` behind a 3-2-1 countdown (client blocks
  move/attack + shows the count, server drops attacks via `meta.frozenUntil`
  and skips frozen bots; poses stay client-authoritative); kill streaks and
  multi chains reset each round (`KillTracker.resetStreaks`, revenge kept).
  Test override `roundFreezeMs`.
