# Capture the Flag (CTF) room mode

## Context

Mineshoot today is free-for-all deathmatch (+ a training range). The user wants a
**Capture the Flag** mode with real tug-of-war instead of "grab flag, run home
unopposed". Decisions made with the user:

- Classic **2 teams (Red/Blue), one flag per team at its base**. (Neutral
  centre flag rejected: carrier gets a half-map head start on respawners.)
- **Continuous** play: score, flag returns, keep playing. Win = first to
  `captureLimit` (3/5/10, default 3) or higher score at time-out; equal → draw.
- Carrier rules (all four): **0.75× speed**, **melee only** (no shooting; in a
  gun-only room a carrier cannot attack at all), **only score while own flag is
  home**, **G drops the flag** (hand-off).
- **Continuous respawn** (3 s, unchanged), spawns on own side near the base.
- **Team choice in the lobby when joining** (Red / Blue / Auto) **and team
  switch mid-match** — always allowed, no balance check; bots re-balance
  themselves when they exist.
- **Bots play CTF simply**: filtered to enemies only, alternate roles
  attacker / defender.
- No friendly fire. Weapon modes (`all/gun/sword`) and weapon drops stay
  orthogonal and unchanged.
- **Dedicated rectangular CTF map** (96×48) from v1, so the carry home is long
  enough for respawning defenders to catch up. Scoring happens anywhere inside
  the **base zone** (radius around the flag stand), not by touching the pole.
- The plan itself is saved to `docs/plans/2026-08-18-ctf-mode.md` for future
  reference (first step of implementation).

Balance reasoning (walk 5.5 b/s, no sprint): on a 96-long map the carrier runs
~85 blocks (~15 s → ~21 s at 0.75×) through the zone where defenders respawn
every 3 s next to their flag; melee-only forces an escort; "own flag must be
home" produces the classic double-carry standoff; three lanes (raised centre
ridge: short/exposed; two side lanes with cover: safer/longer) give the carrier
choices and defenders intercept points.

## Numbers (new constants, `packages/shared/src/constants.ts`)

```
CTF_WORLD_SX = 96, CTF_WORLD_SZ = 48   (WORLD_SY stays 24)
CTF_CAPTURE_LIMIT_OPTIONS = [3, 5, 10]   CTF_DEFAULT_CAPTURE_LIMIT = 3
FLAG_CARRY_SPEED_SCALE = 0.75            FLAG_RETURN_MS = 20_000
CTF_BASE_ZONE_RADIUS = 4                 (score when inside this radius of own flag stand, carrying, own flag home)
CTF_TEAM_SPAWN_COUNT = 6                 (spawn points nearest own base used for that team)
```
Flag pickup/touch radius = existing `canPickUp()` (`melee.ts:148`, 1.2 horiz /
1.5 dy). Bots steering straight base→base along the z-centre line hit the ridge
ramps (see map), so the naive steer-and-hop pathing works.

## CTF map (`shared/src/worldgen.ts` → new `generateCtfWorld(seed)`)

Refactor: extract the terrain/border/decoration helpers of `generateWorld` so
both generators share them (`fillTerrain(world, noise, raise: (x,z)=>h|null)`,
`borderWall`, `carveRampToward`, `scatterPillars/Walls/Trees(rng, forbidden)`,
`computeSpawnPoints(world, rng, target)`). `GeneratedWorld` gains
`dropZone: {minX,maxX,minZ,maxZ}` (arena: plateau rect; ctf: centre of the
ridge) and, for ctf, `bases: Record<Team, SpawnPoint>`. `generateWorldFor(mode,
seed)` picks the generator; client `game.ts` and the offline sandbox call it.

Layout (x = long axis 0..95, z = 0..47, bases on the z-centre line z=24):
- **Base platforms** x 3..11 (red) / 84..92 (blue), z 18..29, raised to h=6
  with brick edge; the flag stand at (7, 24) / (88, 24); open stair on the
  field side (x 12..13 / 82..83, full width) so it's easy to enter, plus one
  side stair each — the base is a small fort, not a maze.
- **Centre ridge** x 20..75, z 18..29, h=8, brick edge; ramps at both ends on
  the z-centre (toward each base, `RAMP_WIDTH=4`) + one ramp on each long side
  at x≈47 (down to the side lanes). Weapon drops land on x 38..57 of the ridge.
- **Side lanes** z 2..17 and 30..45: noise terrain h 3..5, staggered brick
  cover walls (3 tall, len 5..7) every ~12 blocks alternating sides, a few
  pillars/trees; two cross-cuts (no obstacles) at x≈32 and x≈64 connect lanes.
- Border wall as today. Ramp/base/stair columns are `reserved` (no obstacles).
- Spawn points: `computeSpawnPoints` restricted to x ≤ 22 and x ≥ 73, target
  16 total; `teamSpawns` = nearest 6 to own base.

`worldgen.test.ts` additions: size; both flag stands standable and inside the
world; every column along z=24 from x=7 to x=88 differs ≤1 block in height from
its neighbour (a bot's straight path is walkable); ≥6 spawn points on each
side; determinism (same seed → same blocks).

Follow-ups for the variable size: `validate.ts` `parsePose(raw, sx, sz)` clamps
to the room's world (ArenaRoom passes `this.world.sx/sz`); `drops.ts`
`pickDropSpot(world, rng, avoid, fallback, zone)` takes the `dropZone` instead
of importing `PLATEAU_MIN/MAX`; `pickSpawnFor` (training dummies) passes the
arena zone.

## Shared (`packages/shared/src`) — pure + tested first

  - `ROOM_MODES = ['match','training','ctf']`; new label/badge in lobby.

    `isTeam()`, `teamName()`.
  - `CreateOptions.captureLimit?`, `JoinOptions.team?: Team` (0 = auto),

  - New `MSG.selectTeam` (`SelectTeamMsg = Team`), `MSG.dropFlag`
    (`DropFlagMsg = epoch`), broadcast `MSG.flag`
    (`FlagEventMsg { kind: 'taken'|'dropped'|'returned'|'captured'; team: Team /*flag owner*/; playerId; playerName; redScore; blueScore }`).
  - Helper `isCtf(mode)`.
- `types.ts`: `RankRow.team?: Team`, `RankRow.captures?: number`.
- **New `ctf.ts`** (no deps beyond types/worldgen helpers), with `ctf.test.ts`:
  - Bases come from `generateCtfWorld(seed).bases` (see map section); `ctf.ts`
    only consumes them.
  - `teamSpawns(spawns, base, n=CTF_TEAM_SPAWN_COUNT)` — n spawn points nearest
    the base. Server calls existing `pickSpawn(teamSpawns, enemyTeamAlive, rng)`
    (`spawn.ts:8`).
  - `FlagState { team; status: 'home'|'carried'|'dropped'; x;y;z; carrierId; droppedAt }`.
  - `flagTouch(flag, toucher: {id, team}): 'take'|'pickup'|'return'|null` for a (rev. 5: no `return`, see below)
    player within `canPickUp` range of a flag (enemy touches home/dropped →
    take/pickup; owner touches dropped → return).
  - `canScore(carrier: {team,x,z}, flags, bases): boolean` — carrying the enemy
    flag, own flag `home`, and within `CTF_BASE_ZONE_RADIUS` (horizontal) of the
    own flag stand.
  - `pickTeam(counts: [red, blue], rng)` — smaller team, tie → rng.
  - `botRebalance(counts, botsByTeam)` — which bot to move so |diff| ≤ 1
    (used only when bots exist; humans are never blocked).
  - `matchWinner(red, blue): Team | TEAM_NONE`.
  - `botCtfGoal(role, team, flags, bases): {x,y,z} | null` — attacker: enemy
    flag position (home/dropped) or own base when carrying; defender: own flag
    position (home = base, dropped = spot, carried = carrier's pos → chase).
- `bot.ts`: `BotView` gains `goal?: Vec3 | null` and `carrying?: boolean`.
  `compute()`: when `carrying` → force `WEAPON_SWORD` (or no attack in gun-only)
  and always steer to `goal` (still swing if an enemy is within sword range);
  otherwise when no enemy in sight, walk to `goal` if set (else existing
  wander). `BotOptions.role?: 'attack'|'defend'` is server-side info only; goal
  is computed by the server each tick with `botCtfGoal`. Tests in `bot.test.ts`.
- `ranking.ts`: keep `rankPlayers`; add `rankCtf(rows)` = captures desc, then
  kills desc, deaths asc, name (used only in ctf).
- `index.ts` exports `ctf.ts`.

## Server (`packages/server/src`)

- `rooms/schema.ts`: `PlayerSchema.team: uint8`, `PlayerSchema.captures: uint16`;
  new `FlagSchema { team, status ('home'|'carried'|'dropped'), x,y,z, carrierId }`;
  `RoomState.flags: MapSchema<FlagSchema>` keyed `'1'|'2'` (team), `redScore`,
  `blueScore`, `captureLimit` (uint8).
- `rooms/validate.ts` (+ `validate.test.ts`): `parseTeam` (0/1/2 else 0),
  `parseCaptureLimit` (must be in options, else default), `parseSelectTeam`,
  `parseDropFlag` (epoch number).
- `rooms/ArenaRoom.ts`:
  - `onCreate`: `generateWorldFor(mode, seed)`; mode `ctf` → flags at
    `gen.bases`, both `home`, set `captureLimit`; bots alternate teams (`bot1`
    red, `bot2` blue …) with role attack/defend alternating within a team;
    metadata `captureLimit`, `teams` (refresh in `updateTeamMeta()` on
    join/leave/switch). Drops use `gen.dropZone`; `parsePose` gets
    `world.sx/sz`.
  - `onJoin(client, {nickname, team})`: `team = parseTeam || pickTeam`; in ctf
    set `p.color = team === TEAM_RED ? 0 : 1` (`PLAYER_COLORS[0]` is red,
    `[1]` blue → humanoid/nametag colour by team with no renderer change);
    `freeColor()` unchanged for other modes. Unspawned park position: own side.
  - `handleSelectTeam`: playing && ctf && team valid && ≠ current → set team &
    colour; if alive: drop carried flag, mark dead (deaths not incremented, no
    kill msg), `respawnAt = now + respawnMs`; then `botRebalance` (moving a bot
    = same as switching it). Allowed before `ready` too (from the overlay).
  - `handleDropFlag`: `actor()` + carrying → `dropFlagAt(flag, p, now)`.
  - `spawn()`: ctf → `pickSpawn(teamSpawns(...), aliveEnemiesOfTeam, rng)`.
  - `targetsExcluding()` and bot `enemies`: skip same-team players in ctf (no
    friendly fire, bots never target teammates).
  - `attackShoot()`: in ctf a carrier's shot is dropped (bots included);
    `handleCharge/attackSwing` unchanged (melee allowed).
  - `kill()`: victim carrying → `dropFlagAt` + broadcast `flag: dropped`.
  - `onLeave()`: carrier leaves → drop at last pose.
  - `tickFlags(now)` from `tickLifecycle`: dropped flags past `FLAG_RETURN_MS`
    → home (`returned` event); for each alive player: if `canScore` →
    `redScore/blueScore++`, `p.captures++`, enemy flag home, `captured` event,
    `if score >= captureLimit → endMatch()`; else for each flag in `canPickUp`
    range apply `flagTouch` (take/pickup → carried; return → home).
  - `tickBots()`: `BotView` gets `goal` (`botCtfGoal`) and `carrying`.
  - `endMatch()` unchanged (phase 'ended'); winner derived client-side from
    scores.
- Integration test (`arenaRoom.integration.test.ts`): create `mode:'ctf'`,
  `bots:0`, `captureLimit:1`, `testOverrides {respawnMs, spawnProtectMs:0}`;
  two clients join with `team` 1 and 2; assert teams/flags/spawn sides; client A
  sends poses onto flag B → `flag: taken`, `flags['2'].carrierId===A`; A poses
  to base A → `captured`, `redScore 1`, phase `ended`. Second test: carrier killed
  → dropped → owner touch returns; `dropFlag` message; `selectTeam` switches +
  metadata `teams`; carrier `shoot` ignored (no `shot` broadcast); bots room:
  `bots:2` → one per team.

## Changes made during implementation (2026-08-18)

- **`FLAG_DROP_GRACE_MS = 1500`**: putting a flag down with `G` while standing
  on it re-picked it up on the next tick; the dropper now cannot take it back
  for 1.5 s (others can immediately).
- **Faster drops in CTF** (user request): `CTF_DROP_INTERVAL_MIN/MAX_MS =
  12 s / 22 s`, `CTF_DROP_MAX_ACTIVE = 5` (`melee.ts`), applied in `onCreate`.
- **Bots rebalance on join and leave too**, not only on `selectTeam` (a human
  insisting on the bigger side at join time is evened out by a bot).
- Bot patrol around a goal uses the waypoints within `GOAL_PATROL_RADIUS`, or
  the 3 nearest ones when none are close, so a defender never wanders across
  the map.
- `bases` are part of `GeneratedWorld` for every generator (zeros for the
  arena) so `ArenaRoom` needs no mode branching to read them.
- Client renders carried flags at the carrier's *rendered* (interpolated)
  position via `RemotePlayers.position()`; nothing was added to `humanoid.ts`.
- `scripts/smoke.mjs` gained a CTF scenario (create CTF room → Bob joins Blue
  from the lobby → Alice takes the blue flag → scores in the base zone).

## Revision 2 (2026-08-18, after the first playtest)

- **Map redesigned**: the long centre ridge and the staggered slalom walls
  read as "a weird long road" in play. New layout (still 96×48, still with a
  walkable centre line for bots): terrain and every structure are **mirrored
  across the middle**; forts at both ends now have a one-block parapet, a
  6-wide gate on the field side and a 4-wide stair on each flank; a **16×12
  central plateau** (h 9, four ramps, corner posts) replaces the ridge and is
  the drop zone; rolling ground 3..6; mirrored 5×5 watchtowers at (22,6)/(22,37)
  and their east twins; 6 short walls, 3 pillars, 5 trees placed on the west
  half and mirrored. Helpers `platformAt/pillarAt/treeAt/wallCells/scatterMirrored`.
- **Bots play offence** (user request): the attack/defend roles are gone;
  `botCtfGoal(team, id, self, flags, bases)` → enemy flag (or a teammate
  carrying it, escort), return the own flag only if it lies closer than the
  enemy flag, chase the enemy carrying it within `BOT_CHASE_RADIUS = 20`,
  carriers go home.

## Revision 5 (2026-08-19): return your flag by carrying it home

Player feedback: touching your own dropped flag sent it straight home, which
felt like a bug — you should have to bring it back yourself. Rule change:

- `flagTouch(flag, toucher: {id, team}, flags)` → `'take' | 'pickup' | null`;
  the owning team now **picks up** its dropped flag (the `'return'` touch is
  gone) and a player already carrying a flag can't touch another (one flag
  per player; the server also stops after one successful touch per tick).
- New `canReturn(player, flags, bases)`: carrying the own flag inside the own
  base zone (`CTF_BASE_ZONE_RADIUS`) → `returnFlag` (`returned` event with the
  carrier's id). `tickFlags` checks it right after `canScore`.
- Carrying your own flag uses the same carrier rules (0.75× speed, melee-only,
  `G` drops, death drops, everyone sees the light column). Untouched dropped
  flags still auto-return after `FLAG_RETURN_MS`.
- Bots: a carrier of either flag heads home; a carrier who can't score no
  longer detours to a dropped own flag (it couldn't pick it up anyway) —
  teammates fetch it. Non-carriers pick up the own flag and carry it back.
- Feed: `🚩 X picked up the Red flag` when the owning team lifts it.
