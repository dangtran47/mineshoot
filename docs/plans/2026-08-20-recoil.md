# Recoil — masterable per-gun spray patterns (2026-08-20)

## Context

Guns had no recoil: aim stayed glued to the crosshair and full-auto spraying
was free. We want CSGO-style recoil the player can *master*: each consecutive
shot in a burst kicks the camera along a fixed per-gun pattern (mostly up,
with a deterministic horizontal S-drift on the automatics), and the part of
the kick the player did not compensate drifts back to the original aim
shortly after the burst ends.

## Decisions

- **Deterministic pattern, no bloom.** `spreadDeg` stays a fixed server-side
  cone; recoil is a camera kick only. Masterable = learnable = no randomness.
- **Client-side, gameplay-real.** Aim is client-authoritative (the server
  re-raycasts from the yaw/pitch in `MSG.shoot`), so kicking `PointerLook`
  changes the real bullet path with zero server changes. The kick is applied
  *after* the shot message is built: the kick affects the *next* shot.
- **Partial recovery.** A controller tracks the un-compensated recoil offset;
  downward/counter mouse movement is subtracted from it, and once the burst
  ends the remainder recovers toward zero — pulling down during a spray never
  overshoots after release.
- **Bots are unaffected** (they keep their skill-profile aim error).

## Numbers (initial tuning)

Pattern tables live in `packages/shared/src/recoil.ts` (`RECOIL_PATTERNS`),
indexed by shot number in the burst, clamped to the last entry:

| Gun | Pattern |
| --- | --- |
| Pistol | 1.0° up per shot |
| Rifle | shots 1–4: ~1.3° up; 5–8: up + drift right; 9–12: up + drift left |
| SMG | ~0.7° up, gentle right-then-left zigzag (±0.3°) |
| Shotgun | 3.0° up single punch |
| Sniper | 4.0° up single punch |
| Taser | none |

- Burst resets after `recoilResetMs(spec)` = `max(300, 2 × cooldownMs)`
  without a shot.
- Recovery: `RECOIL_RECOVER_DEG_PER_S = 25`, starts after the same gap.

## Files

- `packages/shared/src/recoil.ts` (+ test) — patterns, `recoilKick()`,
  `recoilResetMs()`, recovery constant. Pure data/math.
- `packages/client/src/game/recoil.ts` (+ test) — `RecoilController`:
  applies kicks to `PointerLook`, tracks compensation, recovers.
- `packages/client/src/input/pointerLock.ts` — `onDelta` hook (applied mouse
  deltas) so the controller can see compensation.
- `packages/client/src/render/viewmodel.ts` — `fire(intensity)` scales the
  existing prop kick per gun.
- `packages/client/src/screens/game.ts` — wiring (kick on fire, update in the
  frame loop, dispose).

## Verification

Shared + client vitest; `npm run build`; `npm run smoke`; manual feel pass
with `make start` (rifle S-curve, compensation, settle-back).
